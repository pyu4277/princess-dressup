# 공주 꾸미기 (Princess Dress-Up)

아이가 혼자서도 막히지 않고 놀 수 있게 만든 공주 꾸미기 게임입니다.

- 광고 없음 · 결제 없음 · 회원 가입 없음
- 인터넷을 쓰지 않습니다 (인터넷 권한 자체가 없습니다)
- 글을 몰라도 그림 단추만으로 놀 수 있습니다
- 옷 · 신발 · 장신구 · 화장 · 네일 · 얼굴 스티커

## 받기

안드로이드 폰에서 아래 링크를 누르면 설치 파일(APK)이 내려받아집니다. 항상 가장 새 버전입니다.

**https://github.com/pyu4277/princess-dressup/releases/latest/download/PrincessDressUp.apk**

PC 화면으로 이 글을 보고 있다면 폰 카메라로 아래 QR 코드를 찍으세요.

![내려받기 QR 코드](qr-download.png)

버전별 파일과 바뀐 점은 [Releases](https://github.com/pyu4277/princess-dressup/releases) 에 있습니다.

## 설치 방법 (안드로이드)

1. 위 링크를 폰에서 엽니다. 「이 파일을 내려받을까요」 가 나오면 「다운로드」 를 누릅니다.
2. 내려받기가 끝나면 알림에서 파일을 누르거나, 「내 파일」 앱의 「다운로드」 폴더에서 `PrincessDressUp.apk` 를 누릅니다.
3. 처음이면 「보안상의 이유로 이 출처의 앱을 설치할 수 없습니다」 가 나옵니다. 「설정」 을 눌러 그 앱(크롬 또는 내 파일)의 「이 출처 허용」 을 켠 뒤 뒤로 돌아옵니다.
4. 「설치」 를 누릅니다.
5. 「Play 프로텍트에서 인식하지 못하는 앱」 이라는 안내가 나올 수 있습니다. 구글 플레이에 올리지 않은 앱이라 나오는 안내입니다. 「세부정보 더보기」 를 누른 뒤 「무시하고 설치」 를 누르면 됩니다.
6. 설치가 끝나면 앱 목록에서 「PrincessDressUp」 을 엽니다.

## 새 버전으로 올리기

같은 링크에서 다시 받아 그대로 설치하면 됩니다. 앱을 지우지 않고 덮어 설치하면 꾸며 놓은 모습이 그대로 남습니다.

## 필요한 폰

- 안드로이드 7.1 이상
- 64비트(ARM64) 폰 -- 2017년 이후에 나온 대부분의 폰

## 지우기

「설정 > 애플리케이션 > PrincessDressUp > 삭제」. 이 앱은 폰의 다른 정보를 읽거나 바깥으로 보내지 않습니다.
